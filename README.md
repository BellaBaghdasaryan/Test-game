# Sudoku Game

A modern, interactive Sudoku game built with React 19 and TypeScript.

## Features

- Clean, intuitive interface
- Randomly generated Sudoku puzzles
- Keyboard navigation (arrow keys to move, numbers 1-9 to fill, backspace to clear)
- Click to select cells
- Visual feedback for selected cells
- Fixed cells are marked and cannot be edited
- Responsive design

## Getting Started

### Prerequisites

- Node.js 20 or higher

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

### Test

```bash
npm test
```

## How to Play

1. Click "New Game" to generate a new puzzle
2. Click on any empty cell to select it
3. Type a number (1-9) to fill the cell
4. Press Backspace or Delete to clear a cell
5. Use arrow keys to navigate between cells
6. Complete the puzzle by filling all cells with valid numbers
